# orchestra-mcp/pack-ai

AI and LLM integration skills with RAG, embeddings, and vector search

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-ai
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-ai")
```
